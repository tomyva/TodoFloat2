# Todo Float

A small Windows WPF to-do list that stays on top of your desktop.

Features: task categories, statuses, due dates, month calendar, completed-task strike-through, dark/light appearance, adjustable opacity and text size, drag-anywhere header, and a clear-completed action.

## Run

```powershell
cd TodoFloat
dotnet run
```

Requires the .NET 10 SDK and Windows.
